# ølrating.dk

Danske øl, bedømt af dem der drikker dem.

Hjemmesiden er én fil (`index.html`) plus billederne i `img/`. Den kører på GitHub Pages med domænet ølrating.dk (`xn--lrating-p1a.dk` i `CNAME`).

- Tilføj en øl med billede, navn og bedømmelse i fem kategorier
- Toplisten, galleri, siden for hver øl og lignende øl
- Skifter udseende til jul, J-dag, nytår, fastelavn, påske, sankthans og halloween

Lige nu gemmes øl og bedømmelser i den enkelte browser. Næste skridt er en fælles database (Supabase), så alle kan se hinandens øl, og Android-appen kan bruge de samme data.
